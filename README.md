# Idlegame where you manage multiple characters

---------------------------------------------------------------

## keys:

### characters

y,x,c,v,b: switch to test-character 1-5

9: switch to managed mode (see character 1-4 all together)

### classes

6: switch all heros to knight

7: switch all heros to archer

8: switch all heros to mage

### misc

0: restart all maps

### skills

q: shot 5 projectiles (-20°, -10°, 0°, +10°, +20°)

w: shot circle of 36 projectiles (one every 10°)

e: shot projectile with random offset from -20° to +20° (hold for rapid fire)

r: shotgun (shot 49 projectile from -24° to +24° with 1°-steps)

### potions

1-3: use potion-slot 1-3

### autopilot

a: toggle on/off
